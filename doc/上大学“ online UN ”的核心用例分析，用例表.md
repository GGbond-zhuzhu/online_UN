| **编号**     | UC-01                                                        | **名称**   | 校园 E 卡通消费 |
| ------------ | ------------------------------------------------------------ | ---------- | --------------- |
| **执行者**   | 学生                                                         | **优先级** | 高█ 中□ 低□     |
| **描述**     | 学生通过动态生成的 “学生码”，在校内场景（食堂、图书馆等）完成校园一卡通消费，实现交易金额实时扣减、消费记录加密存储，并接收消费结果通知。 | 1          |                 |
| **前置条件** | 1. 学生已完成 “学号 + 教务系统验证码” 双因素认证；                                  2. 高校已通过平台后台解锁 “校园 E 卡通” 定制功能，并完成与本校一卡通系统的 API 对接；                                                                                               3. 学生校园卡账户余额≥本次消费金额；                                                        4. 学生 App 已授权定位权限（临时授权或长期授权均可）。 |            |                 |
| **基本流程** | 1. 发起消费请求（ 学生打开“上大学Online”App，进入“校园服务”模块，点击“校园E卡通”入口，触发消费码生成请求）                                                                                                                          2.调用多源定位模块（系统动作：室内优先通过高校备案 WiFi 热点定位，室外切换为 GPS + 基站定位）                                                                      3. 生成 1 分钟有效期的动态学生码（系统动作：含身份加密标识、时效戳）                                                                                                                 4. 展示学生码（系统动作：App 显示动态二维码）                                   5. 商家扫码后，校验学生码有效性（身份匹配、未过期）及账户余额（高校一卡通系统动作）                                                                                      6. 扣减校园卡余额，生成交易记录并采用 AES 加密存储（系统动作）    7. 向学生发送 App 弹窗 + 系统通知（含交易详情），向商家反馈交易完成确认（系统动作） |            |                 |
| **结束状况** | 正常结束：校园卡余额扣减成功，加密交易记录生成并同步至高校系统，学生和商家接收消费结果通知；                                                                     异常结束：因定位异常、学生码过期、余额不足或网络故障等，消费失败，无余额扣减，提示失败原因。 |            |                 |
| **可选流程** | 无（消费流程为即时性操作，无正常分支场景）                   |            |                 |
| **异常流程** | 步骤2（定位校验） 定位不在高校备案校区范围内 弹窗提示“当前非校内授权场景，无法生成学生码”，提供“重新定位”按钮（10秒未操作则返回上一级）                                                                                                                            步骤4（扫码验证） 学生码已过期（超1分钟） 商家设备提示“码已过期”，App自动刷新生成新码（无需学生手动操作）                                                              步骤5（余额校验） 学生账户余额不足 提示“校园卡余额不足，请点击‘充值’跳转”，提供“充值”“取消”按钮                                                                                          步骤6（记录存储） 网络故障导致记录同步失败 本地缓存交易记录，待网络恢复后自动重试同步（最多3次），同步成功后补发通知 |            |                 |
| **说明**     | 1. **多源定位方案**：室内依赖高校备案 WiFi 热点（如食堂、教学楼 WiFi）实现米级定位，室外采用 GPS + 基站定位保障跨校区连续性；                                   2. **动态码安全规则**：学生码有效期严格限制为 1 分钟，每次生成码值唯一，杜绝截图复用风险；                                                                                            3. **交易记录权限**：加密记录仅学生本人可见，高校需通过 “权限申请 + 平台审核” 流程调取（用于纠纷处理）；                                                                          4. **定位权限管理**：仅在生成学生码时触发定位，消费完成后自动暂停定位，学生可在 App 隐私设置中手动关闭定位（关闭后无法生成学生码）。 |            |                 |
