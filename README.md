# 校园综合服务平台（web_app）

本仓库是一个 **Vue3 跨端校园综合服务平台**，包含：

- **web 子站**：PC/H5 浏览器端（例如二手交易、兼职招聘、校园服务等页面）。
- **app 子包**：基于 UniApp 的移动端（小程序 / App / H5），页面结构与 web 端保持风格统一。
- **backend**：Spring Boot 后端服务，提供登录、二手交易、兼职招聘等接口。
- **common**：前端公共 SDK（例如 `@campus/common`），封装二手/兼职等接口调用。

## 子页面设计规范

### 设计原则

所有从首页跳转的子页面都遵循统一的设计规范：

#### 1. 背景色规范
- **页面背景**：必须使用渐变色背景
- **推荐渐变方案**：
  - 淡紫蓝渐变：`linear-gradient(135deg, #f9f0ff 0%, #e6f7ff 100%)`
  - 淡粉蓝渐变：`linear-gradient(135deg, #ffeef7 0%, #e6f7ff 100%)`
  - 淡绿蓝渐变：`linear-gradient(135deg, #f0fff4 0%, #e6f7ff 100%)`
  - 淡橙蓝渐变：`linear-gradient(135deg, #fff5e6 0%, #e6f7ff 100%)`

#### 2. 单原色马卡龙色系规范

所有非背景元素必须使用单原色（非渐变），采用淡淡的马卡龙色系：

- **淡蓝色**：`#C7CEEA` - 用于卡片、图标背景
- **淡粉色**：`#FFB5D8` - 用于主要按钮、高亮元素
- **淡绿色**：`#A8E6CF` - 用于成功状态、确认按钮
- **淡紫色**：`#D4A5F5` - 用于特殊功能、高级选项
- **淡橙色**：`#FFD3B6` - 用于警告、提醒
- **淡黄色**：`#FFE5B4` - 用于提示、信息
- **淡青色**：`#B8E6E6` - 用于辅助功能
- **淡玫瑰**：`#E8B4CB` - 用于次要按钮

#### 3. 卡片设计规范

- **卡片背景**：`rgba(255, 255, 255, 0.95)` 或 `#FFFFFF`
- **卡片阴影**：`0 8rpx 30rpx rgba(255, 181, 216, 0.12)`
- **卡片圆角**：`24rpx` 或 `20rpx`
- **顶部装饰线**：使用单原色马卡龙色，高度 `4rpx`

#### 4. 按钮设计规范

- **主要按钮**：单原色马卡龙色背景 + 白色文字
- **次要按钮**：白色背景 + 单原色马卡龙色文字和边框
- **图标按钮**：单原色马卡龙色背景 + 白色图标

详细的设计规范文档请参考：`vue3-cross-platform/SUB_PAGE_DESIGN_GUIDE.md`

## 二手交易模块（Secondhand）

### 页面位置
- Web 页面：`packages/web/src/pages/secondhand/index.vue`
- App 页面：`packages/app/src/pages/secondhand/index.vue`

### 布局结构（web 端）
- **顶部导航栏**：使用 `NavBar` 组件，统一站点导航与配色。
- **搜索栏**：支持关键字搜索二手商品（标题 + 描述），样式使用圆角输入框 + 放大镜图标。
- **筛选区**：
  - 品类（教材书籍 / 数码产品 / 服饰鞋包 / 生活用品 / 运动户外 / 其他）
  - 成色（全新 / 9 成新 / 8 成新 / 7 成新 / 6 成及以下）
  - 价格区间（最低价 / 最高价）
  - 校区（主校区 / 东校区 / 西校区）
- **主内容区**：
  - 搜索结果盒子：在用户有搜索或筛选时显示，展示“搜索结果”列表。
  - **猜你喜欢盒子**：始终显示，展示“猜你喜欢”的二手商品卡片（支持随机推荐）。
- **右侧栏**：热门分类、快捷操作、交易提示等信息。
- **页脚**：平台介绍、联系方式、快速链接等。

### 样式说明（web 端）
- 使用 HTML5 语义化结构（`header` / `section` / `footer` 等通过 class 进行抽象）。
- 样式基于 **Flexbox + CSS Grid**：
  - 列表区使用 Grid 实现多列商品卡片自适应布局。
  - 侧边栏和主内容区使用 Flex 实现两列布局。
- 主配色：
  - 主色：`#d81b60`（用于按钮、图标、价格等高亮元素）。
  - 背景：顶部为渐变背景，内容区为白色卡片。
- 响应式：
  - 宽度较小（如手机）时，主内容与侧边栏上下排列，商品卡片列数减少。

### 猜你喜欢（二手）逻辑概述
- 数据来源：
  - 通过 `@campus/common` 中的 `getGoodsList` 接口从后端拉取商品列表。
- 展示规则（目标需求）：
  - 从数据库返回的商品中 **随机选取若干条** 展示在“猜你喜欢”盒子中。
  - 用户 **下拉页面或点击“换一批”** 时，重新随机一组商品进行展示，达到“动态推荐”的效果。

  - 默认从所有兼职岗位中 **随机选取若干条** 展示在“推荐兼职”盒子中。

    - 搜索结果盒子展示当前匹配的岗位。
    - 推荐盒子可以优先展示 **不在搜索结果中的其他岗位**，避免重复。
  - 支持 **点击“换一批”或下拉刷新页面** 时重新随机一组岗位。

## 本次需求：猜你喜欢动态随机推荐

> 目标：**二手交易** 和 **兼职招聘** 的“猜你喜欢/推荐兼职”盒子中的数据，需要实现：
>
> 1. 从数据库返回的列表中 **随机抽取** 部分内容进行展示；
> 2. 用户向下拉（滚动）或点击“换一批”时，可以 **刷新出新的随机内容**。

实现思路（简要）：

1. **后端已经提供列表接口**（二手：`/api/secondhand/list`，兼职：`/api/parttime/list`），前端通过 `@campus/common` 调用。
2. **前端随机推荐逻辑**：
   - 在前端拿到完整列表后，通过简单的随机算法从数组中抽取若干条作为“猜你喜欢”数据源。
   - 使用一个“种子变量”（计数器）驱动 `computed` 重新计算，实现“换一批”刷新效果。
3. **交互方式**：
   - 在“猜你喜欢/推荐兼职”标题右侧增加“换一批”按钮，用户点击即可获得新的随机推荐。
   - 页面滚动到底部时，自动触发一次随机刷新，模拟“向下拉刷新出新的内容”的体验。

## 行程管理模块（Schedule）

### 行程系列功能

行程系列功能允许用户创建包含多个地点的行程，并自动生成最优路线。

#### 功能特点

1. **行程主题设置**：为行程系列设置主题（例如："做饭工作"）
2. **多地点管理**：
   - 通过高德地图API搜索并选择多个地点
   - 支持地点顺序调整（上移/下移）
   - 支持地点删除
3. **自动路线规划**：
   - 使用高德地图路径规划API自动生成最优路线
   - 显示总距离和预计时间
   - 显示详细的路线步骤指引

#### 页面位置

- 行程系列页面：`packages/app/src/pages/schedule/route-series/index.vue`
- 行程编辑页面：`packages/app/src/pages/schedule/edit/index.vue`（已添加行程系列选项）

#### 使用流程

1. 在行程编辑页面，选择"行程系列（多地点）"类型
2. 点击"创建行程系列"按钮，进入行程系列页面
3. 输入行程主题（例如："做饭工作"）
4. 点击"添加地点"按钮，搜索并选择多个地点
5. 点击"生成最优路线"按钮，系统自动规划最优路线
6. 保存行程系列，返回行程编辑页面完成行程创建

#### 技术实现

- **高德地图POI搜索API**：用于地点搜索和选择
- **高德地图路径规划API**：用于生成最优路线（驾车路径规划）
- **API Key配置**：在 `packages/app/vite.config.ts` 中配置高德地图API Key

#### 数据格式

行程系列数据包含以下字段：
- `theme`: 行程主题
- `locations`: 地点数组，每个地点包含：
  - `name`: 地点名称
  - `address`: 地点地址
  - `longitude`: 经度
  - `latitude`: 纬度
- `routeResult`: 路线规划结果（可选），包含：
  - `totalDistance`: 总距离（公里）
  - `totalDuration`: 预计时间（分钟）
  - `steps`: 路线步骤数组

### 课程表管理和时间表格功能

课程表管理和时间表格功能允许用户管理课程表，并通过直观的时间表格视图查看所有课程和行程安排，快速识别空余时间。

#### 功能特点

1. **课程表管理**：
   - 支持手动添加课程（课程名称、星期、时间、地点、教师等）
   - 支持从Excel文件导入课程表（开发中）
   - 支持从图片识别导入课程表（开发中）
   - 支持编辑和删除课程
   - 课程数据保存在本地存储中

2. **时间表格视图**：
   - 以表格形式展示一周的时间安排（周一至周日）
   - 时间段从早上8点到晚上22点，每小时一个时间段
   - 自动整合课程和行程数据
   - 课程显示为粉色背景，行程根据标签显示不同颜色
   - 空余时间用绿色背景标识，方便快速识别
   - 支持切换周次查看不同周的安排
   - 点击空余时间可以快速添加新行程

3. **数据整合**：
   - 课程数据：每周重复的固定课程
   - 行程数据：按日期存储的临时行程
   - 两种数据在时间表格中统一展示，避免时间冲突

#### 页面位置

- 课程表管理页面：`packages/app/src/pages/schedule/course-table/index.vue`
- 添加/编辑课程页面：`packages/app/src/pages/schedule/course-table/add/index.vue`
- 时间表格视图页面：`packages/app/src/pages/schedule/time-table/index.vue`
- 主页面入口：`packages/app/src/pages/schedule/index.vue`（新增课程表和时间表格入口卡片）

#### 使用流程

1. **添加课程**：
   - 在行程管理主页面，点击"课程表管理"卡片
   - 点击"手动添加"按钮
   - 填写课程信息（课程名称、星期、时间、地点、教师等）
   - 保存课程

2. **查看时间表格**：
   - 在行程管理主页面，点击"时间表格"按钮
   - 或从课程表管理页面点击右上角"时间表"按钮
   - 查看一周的时间安排
   - 使用左右箭头切换周次
   - 点击空余时间可以添加新行程

3. **管理课程**：
   - 在课程表管理页面查看所有课程
   - 点击编辑按钮修改课程信息
   - 点击删除按钮删除课程

#### 数据存储

- **课程数据**：存储在本地存储的 `courseTable` 键中
- **行程数据**：存储在本地存储的 `scheduleList` 键中，按日期分组
- 数据格式为JSON字符串，便于后续扩展为后端API集成

#### 时间表格显示规则

- **课程**：每周重复显示，使用粉色背景（#fce4ec）
- **行程**：按日期显示，根据标签使用不同颜色背景
  - 课程标签：粉色（#fce4ec）
  - 考试标签：浅红色（#ffebee）
  - 社团标签：橙色（#fff3e0）
  - 兼职标签：橙色（#fff3e0）
  - 事务标签：灰色（#f5f5f5）
- **空余时间**：绿色背景（#e8f5e9），显示"空闲"标识
- **今天**：表头和单元格使用黄色背景高亮显示

- **安全机制说明区**：以段落形式详细解释数据加密、权限管理、交易安全、隐私保护等机制，帮助非技术用户理解平台是如何保护数据的。
- **安全使用小贴士区**：列出 3～4 条简单易懂的使用建议（如密码安全、线下交易注意事项等），引导用户自我保护。
- **异常兜底区**：当接口和本地数据都不可用时，展示一段基础安全说明和“重新尝试加载安全说明”按钮，避免页面一直停留在“加载中”。

### 样式说明（web 端）

- 整体风格与 `about / privacy / terms` 等说明类页面保持一致，使用浅灰背景 + 白色卡片 + 适度阴影。
- 安全卡片区采用 **CSS Grid** 布局，在宽屏下自适应多列，在窄屏下自动折叠为单列显示。
- 详细说明和小贴士区域采用 **Flex + 块级布局**，保证段落文字有足够行距和留白，阅读压力小。
- 重要提示（如接口错误）使用浅粉色提示条展示，既能引起注意，又不会给用户过度“报错感”。

### 数据与兜底逻辑

- 正常情况下，通过 `@campus/common` 中的 `getSecurityInfo()` 方法，调用后端 `/api/common/security/info` 接口获取四个字段：
  - `encryption`：数据加密传输说明；
  - `locationPermission`：定位权限分级说明；
  - `transactionEncryption`：交易记录加密说明；
  - `dataProtection`：数据保护说明。
- 如果接口请求失败或返回格式异常，前端会使用内置的 `fallbackSecurityInfo` 作为本地兜底数据，仍然渲染安全卡片和说明文字。
- 出现异常时，页面顶部会显示一行友好的错误提示文案，但不会阻止页面继续展示内容，避免用户看到“永远加载不出来”的情况。

- 后续如果有更细分的安全策略（如登录设备管理、异常登录提醒等），可以在当前页面增加独立小节进行说明，并同步更新本 README。
