# 腾讯云人脸识别接口选择指南

## 🎯 游客活体检测功能所需接口

根据 `AuthService.visitorFaceDetect()` 功能需求，您需要勾选以下接口：

### ✅ 核心必需接口（3个）

#### 1. **在线活体检测V3** ⭐ 核心接口
- **位置**：基础服务-V3版本 → 在线活体检测V3
- **功能**：检测用户是否为真实活体（防止照片、视频攻击）
- **用途**：验证游客刷脸时是否为真人
- **必须勾选**：✅ 是

#### 2. **人脸检测V3** ⭐ 基础接口
- **位置**：基础服务-V3版本 → 人脸检测V3
- **功能**：检测图片中是否存在人脸，获取人脸位置、大小等信息
- **用途**：在活体检测前，先检测是否有人脸存在
- **必须勾选**：✅ 是

#### 3. **人脸对比V3** ⭐ 比对接口
- **位置**：基础服务-V3版本 → 人脸对比V3
- **功能**：将当前捕获的人脸与身份证照片进行比对
- **用途**：验证刷脸的人脸是否与身份证照片匹配
- **必须勾选**：✅ 是

---

## 📋 接口功能说明

### 在线活体检测V3
```
功能：判断用户是否为真实活体
输入：人脸照片（Base64编码）
输出：
  - livenessScore: 活体检测分数（0-1）
  - isAlive: 是否为活体（true/false）
```

### 人脸检测V3
```
功能：检测图片中的人脸信息
输入：人脸照片（Base64编码）
输出：
  - faceCount: 人脸数量
  - faceInfos: 人脸位置、大小、角度等信息
```

### 人脸对比V3
```
功能：比对两张人脸照片是否为同一人
输入：
  - faceA: 第一张人脸照片（Base64编码）
  - faceB: 第二张人脸照片（Base64编码，如身份证照片）
输出：
  - score: 相似度分数（0-100）
  - isMatch: 是否匹配（true/false）
```

## 🔄 调用流程

### 游客活体检测完整流程：

```
1. 用户上传人脸照片
   ↓
2. 调用【人脸检测V3】检测是否有人脸
   ↓ (如果检测到人脸)
3. 调用【在线活体检测V3】检测是否为活体
   ↓ (如果是活体)
4. 调用【人脸对比V3】与身份证照片比对
   ↓
5. 返回检测结果
```
