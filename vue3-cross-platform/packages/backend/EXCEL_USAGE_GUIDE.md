# Excel导入导出使用指南

## 📥 Excel导入功能

### 1. 下载模板
访问：`GET /api/schedule/import/template`
- 下载Excel模板文件
- 模板包含所有列的说明

### 2. 填写数据
按照模板格式填写课程信息：
- **课程名称**：必填，如"高等数学"
- **开始时间**：必填，格式：`2024-03-01 08:00:00` 或 `2024-03-01 08:00` 或 `2024-03-01`
- **结束时间**：可选，如果为空则默认为开始时间+1小时
- **课程类型**：可选，如"课程"、"会议"、"活动"等
- **其他字段**：按需填写

### 3. 上传导入
访问：`POST /api/schedule/import/schedule-excel`
- 上传填写好的Excel文件
- 指定学期（如：2024-2025-1）
- 选择是否覆盖已有数据

### 4. 查看结果
返回结果包含：
- `importedCount` - 成功导入数量
- `failedCount` - 失败数量
- `errorMessages` - 错误信息列表
- `message` - 导入结果消息

## 📤 Excel导出功能

### 导出我的课程表
访问：`GET /api/schedule/export/schedule-excel?semester=2024-2025-1`
- 需要登录（Bearer Token）
- 可选参数：`semester` - 学期筛选
- 返回Excel文件，可直接下载

## 📋 Excel格式说明

### 时间格式支持
- `yyyy-MM-dd HH:mm:ss` - 完整格式，如：2024-03-01 08:00:00
- `yyyy-MM-dd HH:mm` - 简化格式，如：2024-03-01 08:00
- `yyyy-MM-dd` - 日期格式，如：2024-03-01（时间默认为00:00:00）

### 类型枚举值
- **课程类型**：课程、会议、活动、考试、作业、个人事务、团队事务、其他
- **提醒类型**：不提醒、提前5分钟、提前15分钟、提前30分钟、提前1小时、提前1天、自定义
- **是否字段**：是、否、true、false、1、0

## ⚠️ 注意事项

1. **文件格式**：仅支持 `.xlsx` 和 `.xls` 格式
2. **表头**：第一行必须是表头，会被自动跳过
3. **必填字段**：课程名称和开始时间是必填的
4. **时间格式**：建议使用 `yyyy-MM-dd HH:mm:ss` 格式
5. **空行**：空行会被自动跳过
6. **错误处理**：如果某行数据有错误，会跳过该行并记录错误信息，不影响其他行的导入

## 🎯 最佳实践

1. **先下载模板**：使用模板可以确保格式正确
2. **批量导入**：一次可以导入多门课程
3. **检查结果**：导入后查看错误信息，修正后重新导入失败的数据
4. **定期导出**：定期导出备份，防止数据丢失
