# ⚠️ 立即执行：更新数据库密码

## 🎯 必须执行这一步才能正常登录！

在测试登录之前，**必须先更新数据库中的密码**，否则会返回500错误。

## 📝 需要执行的SQL（就这3行，复制粘贴即可）

```sql
USE campus_db;

UPDATE `user` SET `password` = '$2a$10$N.zmdr9k7uOCQb376NoUnuTJ8iAt6Z5EHsM8lE9lBOsl7iwy8pLKO' WHERE `username` IN ('zhangsan', 'lisi', 'wangwu', 'admin');
```

## 🔧 如何执行（选择一种方法）

### 方法1：MySQL命令行（推荐）

1. 按 `Win + R`，输入 `cmd`，回车
2. 输入：`mysql -u root -p`
3. 输入MySQL密码（输入时不会显示）
4. 复制上面的3行SQL，粘贴到命令行
5. 每行后按回车执行
6. 看到 "4 row(s) affected" 表示成功
7. 输入 `exit` 退出

### 方法2：MySQL Workbench

1. 打开MySQL Workbench
2. 连接到数据库
3. 点击"SQL Editor"（SQL编辑器）
4. 复制上面的3行SQL，粘贴
5. 点击执行按钮（⚡图标）
6. 看到 "4 row(s) affected" 表示成功

### 方法3：Navicat或其他工具

1. 连接到MySQL
2. 选择 `campus_db` 数据库
3. 打开SQL查询窗口
4. 复制SQL执行

## ✅ 验证是否成功

## ⚠️ 重要说明

- **只更新4个测试用户**：不会影响其他用户
- **原始密码不变**：所有账号的密码仍然是 `123456`
- **安全**：只更新密码字段，不会删除数据
