**方法2：检查端口**
```powershell

```

**方法3：查看启动日志**

- 看到 `Started BackendApplication` 表示启动成功

## ✅ 测试步骤

### 第一步：访问API文档
1. 打开浏览器
2. 访问：http://localhost:8080/doc.html
3. 确认页面正常显示

### 第二步：测试用户注册
1. 在Knife4j中找到 `POST /api/user/register`
2. 点击"调试"
3. 填写测试数据：
   ```json
   {
     "username": "test001",
     "password": "123456",
     "confirmPassword": "123456",
     "nickname": "测试用户",
     "role": "TOURIST",
     "schoolId": 1
   }
   ```
4. 点击"发送请求"
5. 查看响应结果

### 第三步：测试用户登录
1. 找到 `POST /api/user/login`
2. 填写：
   ```json
   {
     "username": "test001",
     "password": "123456"
   }
   ```
3. **保存返回的token**（后续接口需要）

### 第四步：测试其他功能
使用保存的token测试其他接口：
- 浏览记录功能
- 收藏功能
- 消息和聊天
- 行程管理
