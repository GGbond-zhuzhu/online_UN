# 外部接口需求清单

## 📋 说明

本文档列出了系统开发中需要对接的外部接口。当开发到这些功能时，需要您去申请相应的接口权限和API Key。

---

## 🔴 需要立即申请的外部接口

### 1. 教务系统对接（学生身份认证）✅ 已使用信息表替代

**功能**：`AuthService.applyStudentAuth()` - 学生身份认证申请

**当前实现**：
- ✅ 使用 `student_info` 表进行学生身份验证
- ✅ 高校管理员可以导入或手动添加学生信息
- ✅ 支持Excel批量导入学生信息
- ✅ 验证学号、姓名、身份证号是否匹配

**替代方案**：
- 已创建 `student_info` 表存储学生信息
- 高校管理员通过 `POST /api/university/students/import` 导入学生信息
- 认证时从 `student_info` 表查询验证

**可选：教务系统接口对接**（如果后续需要）
- **接口名称**：学生学号验证接口
- **接口功能**：验证学号、姓名、身份证号是否匹配
- **接口类型**：RESTful API 或 Web Service
- **请求参数**：
  - `studentId` - 学号
  - `name` - 姓名
  - `idCard` - 身份证号
  - `verificationCode` - 教务系统验证码（可选）
- **返回数据**：
  - `isValid` - 是否有效
  - `studentInfo` - 学生信息（姓名、专业、年级等）

**对接方式**：
- 需要与高校的教务系统对接
- 可能需要SSO单点登录或API Token认证
- 建议使用HTTPS加密传输

**申请对象**：各高校的教务系统管理部门（可选，当前已使用信息表）

**优先级**：🟢 低（已使用信息表替代，可选对接）

### 3. 人脸识别SDK（游客活体检测）

**功能**：`AuthService.visitorFaceDetect()` - 游客刷脸活体检测

**需要SDK/API**：
- **服务商选择**：
  - 腾讯云人脸识别
  - 阿里云人脸识别
  - 百度AI人脸识别
  - 旷视Face++

**推荐方案**：腾讯云人脸识别（稳定性好，文档完善）

**需要接口**：
- **接口名称**：人脸活体检测接口
- **接口功能**：
  - 人脸检测
  - 活体检测（防止照片攻击）
  - 人脸比对（与身份证照片比对）
- **请求参数**：
  - `faceImage` - 人脸照片（Base64编码或URL）
  - `idCardImage` - 身份证照片（可选，用于比对）
- **返回数据**：
  - `livenessScore` - 活体检测分数（0-1）
  - `isAlive` - 是否为活体
  - `faceMatchScore` - 人脸比对分数（0-1，如果有身份证照片）

**申请步骤**：
1. 注册腾讯云账号
2. 开通人脸识别服务
3. 创建API密钥（SecretId、SecretKey）
4. 配置服务地域（建议选择离用户最近的地域）

**申请对象**：腾讯云（或其他云服务商）

**优先级**：🟡 中（游客功能）

**费用说明**：
- 腾讯云人脸识别：按调用次数计费
- 活体检测：约0.01-0.05元/次
- 建议申请免费额度或按量付费

### 4. 公司验证API（商户资格校验）

**功能**：`MerchantService.verifyCompany()` - 公司资格智能校验

**需要接口**：
- **服务商选择**：
  - 天眼查API
  - 企查查API
  - 国家企业信用信息公示系统API

**推荐方案**：天眼查API（数据准确，接口稳定）

**需要接口**：
- **接口名称**：企业信息查询接口
- **接口功能**：
  - 根据统一社会信用代码查询企业信息
  - 验证企业名称是否匹配
  - 获取企业基本信息（法人、注册资本、成立日期等）
- **请求参数**：
  - `creditCode` - 统一社会信用代码
  - `companyName` - 公司名称
- **返回数据**：
  - `isValid` - 是否有效
  - `companyInfo` - 企业信息
  - `legalPerson` - 法人姓名
  - `registeredCapital` - 注册资本
  - `establishDate` - 成立日期

**申请步骤**：
1. 注册天眼查账号
2. 申请API接口权限
3. 获取API Key和Secret
4. 查看接口文档和调用限制

**申请对象**：天眼查（https://open.tianyancha.com/）

**优先级**：🟡 中（商户功能）

**费用说明**：
- 天眼查API：按调用次数计费
- 企业信息查询：约0.1-0.5元/次
- 建议申请试用额度或按量付费

### 5. 支付系统对接（保证金支付）

**功能**：`MerchantService.payDeposit()` - 商户缴纳保证金

**需要接口**：
- **支付方式**：
  - 支付宝支付
  - 微信支付
  - 银联支付（可选）

**推荐方案**：同时对接支付宝和微信支付

#### 5.1 支付宝支付

**需要接口**：
- **接口名称**：支付宝统一收单下单接口
- **接口功能**：创建支付订单，返回支付链接或二维码
- **接口类型**：RESTful API
- **请求参数**：
  - `outTradeNo` - 商户订单号
  - `totalAmount` - 订单总金额
  - `subject` - 订单标题
  - `returnUrl` - 支付成功回调地址
- **返回数据**：
  - `tradeNo` - 支付宝交易号
  - `payUrl` - 支付链接（PC端）
  - `qrCode` - 支付二维码（移动端）

**申请步骤**：
1. 注册支付宝企业账号
2. 申请开放平台账号
3. 创建应用，获取AppID
4. 配置应用密钥（RSA2）
5. 申请支付权限
6. 配置回调地址

**申请对象**：支付宝开放平台（https://open.alipay.com/）

**优先级**：🟡 中（商户功能）

#### 5.2 微信支付

**需要接口**：
- **接口名称**：微信支付统一下单接口
- **接口功能**：创建支付订单，返回支付链接或二维码
- **接口类型**：RESTful API
- **请求参数**：
  - `out_trade_no` - 商户订单号
  - `total_fee` - 订单总金额（分）
  - `body` - 商品描述
  - `notify_url` - 支付结果通知地址
- **返回数据**：
  - `prepay_id` - 预支付交易会话ID
  - `code_url` - 支付二维码链接

**申请步骤**：
1. 注册微信支付商户号
2. 申请微信支付接口权限
3. 配置API密钥
4. 配置支付回调地址
5. 申请支付证书（用于退款等功能）

**申请对象**：微信支付商户平台（https://pay.weixin.qq.com/）

**优先级**：🟡 中（商户功能）

**费用说明**：
- 支付宝/微信支付：按交易金额收取手续费
- 费率：约0.6%-1%（根据行业和交易量）
- 保证金支付建议使用企业支付接口

## 📝 接口对接注意事项

### 1. 安全性
- 所有API Key和Secret必须存储在配置文件中，不要硬编码
- 使用环境变量或配置中心管理敏感信息
- 生产环境和测试环境使用不同的API Key

### 2. 错误处理
- 实现完善的错误处理和重试机制
- 记录API调用日志，便于排查问题
- 设置合理的超时时间

### 3. 性能优化
- 实现接口调用缓存（如企业信息查询）
- 批量处理减少API调用次数
- 使用异步调用提高响应速度

### 4. 成本控制
- 监控API调用次数和费用
- 设置调用频率限制
- 合理使用免费额度
