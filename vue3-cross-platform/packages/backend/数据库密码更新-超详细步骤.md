# 数据库密码更新 - 超详细步骤（不会出错版）

## 🎯 目标

将数据库中的4个测试用户的密码从MD5格式更新为BCrypt格式，以便能够正常登录。

## 📝 需要执行的SQL（就这3行）

```sql
USE campus_db;

UPDATE `user` SET `password` = '$2a$10$N.zmdr9k7uOCQb376NoUnuTJ8iAt6Z5EHsM8lE9lBOsl7iwy8pLKO' WHERE `username` IN ('zhangsan', 'lisi', 'wangwu', 'admin');
```

## 🔧 执行方法（选择一种）

### 方法1：MySQL命令行（最简单）

1. **打开命令提示符（CMD）**
   - 按 `Win + R`
   - 输入 `cmd`，回车

2. **连接到MySQL**
   ```bash
   mysql -u root -p
   ```
   - 输入MySQL密码（输入时不会显示，直接输入后回车）

3. **复制粘贴这3行SQL**
   ```sql
   USE campus_db;
   UPDATE `user` SET `password` = '$2a$10$N.zmdr9k7uOCQb376NoUnuTJ8iAt6Z5EHsM8lE9lBOsl7iwy8pLKO' WHERE `username` IN ('zhangsan', 'lisi', 'wangwu', 'admin');
   ```
   - 每行后按回车执行
   - 应该看到：`Query OK, 4 rows affected`

4. **完成！** 输入 `exit` 退出

### 方法2：MySQL Workbench（图形界面）

1. **打开MySQL Workbench**
2. **连接到数据库**（点击连接）
3. **点击"SQL Editor"**（SQL编辑器）
4. **复制粘贴这3行SQL**：
   ```sql
   USE campus_db;
   UPDATE `user` SET `password` = '$2a$10$N.zmdr9k7uOCQb376NoUnuTJ8iAt6Z5EHsM8lE9lBOsl7iwy8pLKO' WHERE `username` IN ('zhangsan', 'lisi', 'wangwu', 'admin');
   ```
5. **点击执行按钮**（⚡图标，或按Ctrl+Enter）
6. **查看结果**，应该显示 "4 row(s) affected"

### 方法3：Navicat或其他工具

1. **打开数据库工具**
2. **连接到MySQL**
3. **选择 `campus_db` 数据库**
4. **打开SQL查询窗口**
5. **复制粘贴SQL并执行**

## ✅ 验证是否成功

执行以下SQL查看结果：

```sql
SELECT username, LEFT(password, 30) as password_preview 
FROM `user` 
WHERE username IN ('zhangsan', 'lisi', 'wangwu', 'admin');
```

**成功标志**：所有密码都应该以 `$2a$10$N.zmdr9k7uOCQb376No` 开头

## 🎯 更新后测试

更新完成后，访问 http://localhost:8080/doc.html 测试登录：

1. 找到"用户管理" -> "用户登录"
2. 输入：
   ```json
   {
     "username": "zhangsan",
     "password": "123456"
   }
   ```
3. 应该能成功返回Token

## ⚠️ 重要说明

- **只更新4个测试用户**：zhangsan, lisi, wangwu, admin
- **不影响其他用户**：WHERE条件确保只更新这4个用户
- **原始密码不变**：所有账号的密码仍然是 `123456`
- **安全**：这个SQL只更新密码字段，不会删除或修改其他数据

## 📋 如果执行出错

### 错误1：Unknown database 'campus_db'
**解决**：数据库不存在，需要先创建数据库，或者检查数据库名称是否正确

### 错误2：Table 'user' doesn't exist
**解决**：表不存在，需要先执行 `init.sql` 创建表结构

### 错误3：Access denied
**解决**：MySQL用户名或密码错误，检查连接信息

更新完成后，就可以正常登录测试了！
