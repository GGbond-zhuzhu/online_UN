# 完整测试指南 - 从更新密码到测试接口

## 📋 第一步：更新数据库密码（必须执行）

### 最简单的方法：复制这3行SQL执行

```sql
USE campus_db;

UPDATE `user` SET `password` = '$2a$10$N.zmdr9k7uOCQb376NoUnuTJ8iAt6Z5EHsM8lE9lBOsl7iwy8pLKO' WHERE `username` IN ('zhangsan', 'lisi', 'wangwu', 'admin');
```

### 执行步骤

**方法A：MySQL命令行**
1. 打开CMD，输入：`mysql -u root -p`
2. 输入MySQL密码
3. 复制上面的3行SQL，粘贴执行
4. 看到 "4 row(s) affected" 表示成功

**方法B：MySQL Workbench**
1. 打开MySQL Workbench
2. 连接到数据库
3. 打开SQL编辑器
4. 复制上面的3行SQL，粘贴执行
5. 点击执行按钮（⚡）

**方法C：Navicat**
1. 连接到MySQL
2. 选择 `campus_db` 数据库
3. 打开查询窗口
4. 复制SQL执行

### ✅ 验证更新成功

执行这个SQL查看：
```sql
SELECT username, LEFT(password, 30) as password_preview FROM `user` WHERE username IN ('zhangsan', 'lisi', 'wangwu', 'admin');
```

应该看到所有密码都以 `$2a$10$N.zmdr9k7uOCQb376No` 开头

## 🚀 第二步：确认服务已启动

### 检查服务状态

1. **访问API文档**：http://localhost:8080/doc.html
2. **如果无法访问**：
   - 等待30秒后重试

### 服务启动标志

控制台应该显示：
```

```

## 🧪 第三步：测试登录接口

### 方法1：使用Knife4j文档（推荐）

1. **打开浏览器**，访问：http://localhost:8080/doc.html

2. **找到登录接口**：
   - 在左侧菜单中找到 **"用户管理"**
   - 展开后找到 **"用户登录"** 接口

3. **点击"调试"按钮**

4. **输入测试数据**：
   ```json
   {
     "username": "zhangsan",
     "password": "123456"
   }
   ```

5. **点击"发送请求"**

6. **查看结果**：
   - ✅ **成功**：返回200状态码，包含token字段
   - ❌ **失败**：返回500错误（说明密码未更新）或401错误（用户名密码错误）

### 方法2：使用curl命令

```bash
curl -X POST http://localhost:8080/api/user/login ^
  -H "Content-Type: application/json" ^
  -d "{\"username\":\"zhangsan\",\"password\":\"123456\"}"
```

### 方法3：使用Postman

1. 创建新请求
2. 方法：POST
3. URL：http://localhost:8080/api/user/login
4. Headers：Content-Type: application/json
5. Body（raw JSON）：
   ```json
   {
     "username": "zhangsan",
     "password": "123456"
   }
   ```
6. 发送请求

## ✅ 成功标志

登录成功应该返回类似这样的响应：

```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "userId": 1,
    "username": "zhangsan",
    "role": "STUDENT",
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "expiresIn": 7200
  }
}
```

## 🔑 设置Token（测试其他接口）

1. **复制返回的token值**
2. **在Knife4j文档中**：
   - 点击右上角的 **"Authorize"** 按钮
   - 输入：`Bearer {你的token}`
   - 点击"确定"
3. **现在可以测试所有需要登录的接口了**

## 🐛 常见问题

### 问题1：登录返回500错误

**原因**：数据库密码未更新

**解决**：执行第一步的SQL更新密码

### 问题2：登录返回401错误

**原因**：用户名或密码错误

**解决**：确认使用正确的测试账号

### 问题3：无法访问API文档

**原因**：服务未启动或启动失败

**解决**：
1. 检查控制台日志
2. 确认MySQL服务已启动
3. 确认数据库配置正确
