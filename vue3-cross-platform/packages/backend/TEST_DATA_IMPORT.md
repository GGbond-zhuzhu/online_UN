## 🚀 导入方式

### 方式一：执行 init.sql 文件（推荐）

如果数据库还没有创建，直接执行整个 `init.sql` 文件即可：

```bash
# 使用MySQL命令行
mysql -u root -p < src/main/resources/init.sql

# 或者使用MySQL客户端工具（如Navicat、DBeaver等）执行整个文件
```

**注意**：`INSERT IGNORE` 语句会跳过已存在的数据，可以安全地重复执行。

## ✅ 验证数据导入

导入完成后，可以通过以下方式验证：

### 1. 查询学生信息

```sql
-- 查询所有学生
SELECT * FROM student_info WHERE is_deleted = 0;

-- 查询清华大学的学生
SELECT * FROM student_info WHERE school_id = 1 AND is_deleted = 0;

-- 按年级统计
SELECT grade, COUNT(*) as count FROM student_info WHERE school_id = 1 AND is_deleted = 0 GROUP BY grade;
```

### 2. 查询教师信息

```sql
-- 查询所有教师
SELECT * FROM teacher_info WHERE is_deleted = 0;

-- 查询清华大学的教师
SELECT * FROM teacher_info WHERE school_id = 1 AND is_deleted = 0;

-- 按部门统计
SELECT department, COUNT(*) as count FROM teacher_info WHERE school_id = 1 AND is_deleted = 0 GROUP BY department;
```

### 3. 通过API接口查询

- **获取学生列表**：`GET /api/university/students?page=1&size=10`
- **获取教师列表**：`GET /api/university/teachers?page=1&size=10`

## 📝 注意事项

1. **身份证号格式**：测试数据中的身份证号都是示例数据，实际使用时请使用真实身份证号
2. **学校ID**：确保 `school_id` 对应的学校在 `university` 表中存在
3. **唯一性约束**：每个学校内的学号/工号必须唯一
4. **状态字段**：
   - 学生状态：`ACTIVE`（在校）、`GRADUATED`（已毕业）、`SUSPENDED`（休学）
   - 教师状态：`ACTIVE`（在职）、`RESIGNED`（已离职）、`SUSPENDED`（停职）
