# 个人动态发布界面设计说明

## 功能概述

个人动态发布页面是一个参考微信朋友圈和小红书设计的社交动态发布功能，允许用户分享校园生活、发布图文动态。

## 设计特点

### 1. 配色方案
- **主色调**：玫红色（#FF69B4），用于突出发布按钮、重要图标和强调元素
- **马卡龙配色**：
  - 淡粉色（#FFF0F5, #FFB6C1）：位置图标背景、输入框边框
  - 淡蓝色（#F0F8FF, #87CEEB）：话题图标背景
  - 淡黄色（#FFD700）：提醒图标
  - 淡绿色（#E0F7FA）：其他辅助元素

### 2. 界面布局
- **顶部导航栏**：自定义导航栏，包含取消按钮、标题和发布按钮
- **用户信息卡片**：显示用户头像、昵称和发布时间
- **文字输入区**：大文本输入框，支持最多500字，实时显示字数统计
- **图片上传区**：网格布局，最多支持9张图片，支持预览和删除
- **功能选项区**：位置、隐私设置、@提醒、话题标签
- **底部工具栏**：表情、图片、位置快捷入口

## 功能列表

### 核心功能
1. **文字输入**
   - 支持多行文本输入
   - 最多500字限制
   - 实时字数统计
   - 超过450字时显示警告颜色

2. **图片上传**
   - 最多上传9张图片
   - 支持相册选择和拍照
   - 图片预览功能
   - 单张删除功能
   - 图片压缩处理

3. **位置信息**
   - 选择当前位置
   - 显示位置名称
   - 支持取消位置

4. **隐私设置**
   - 公开：所有人可见
   - 仅好友可见：仅好友可见
   - 仅自己可见：仅自己可见
   - 底部弹出选择器

5. **@提醒功能**
   - 提醒指定用户查看动态
   - 显示已选择人数
   - （功能开发中）

6. **话题标签**
   - 添加话题标签
   - 支持多个话题
   - 显示话题数量

7. **表情选择**
   - 常用表情快捷选择
   - 插入到文字内容中
   - 可展开/收起

### 增强功能
1. **实时时间显示**：显示当前发布时间
2. **字数统计**：实时显示已输入字数
3. **图片预览**：点击图片可全屏预览
4. **表单验证**：发布前验证必填项
5. **加载状态**：发布时显示加载状态
6. **取消确认**：有内容时取消会提示确认

## 页面路由

- **路径**：`/pages/moment/publish/index`
- **导航栏**：自定义导航栏（navigationStyle: custom）
- **标题**：发布动态

## 使用方式

### 访问页面
```javascript
uni.navigateTo({
  url: '/pages/moment/publish/index'
})
```

### 发布流程
1. 用户进入发布页面
2. 输入文字内容（可选）
3. 添加图片（可选，最多9张）
4. 选择位置（可选）
5. 设置隐私权限（默认公开）
6. 添加@提醒（可选）
7. 添加话题标签（可选）
8. 点击发布按钮
9. 系统验证并提交
10. 发布成功后返回上一页

## 技术实现

### 组件结构
- Vue3 Composition API
- TypeScript类型支持
- 响应式数据管理
- 自定义样式（SCSS）

### 主要依赖
- `uni-icons`：图标组件
- `uni.chooseImage`：图片选择API
- `uni.chooseLocation`：位置选择API
- `uni.previewImage`：图片预览API
- `uni.showModal`：模态框API

### 样式特点
- 渐变背景：顶部淡粉色到淡蓝色
- 圆角卡片：所有卡片使用20rpx圆角
- 阴影效果：卡片使用柔和阴影
- 动画效果：弹出层使用淡入和滑入动画
- 响应式布局：适配不同屏幕尺寸

## 设计参考

### 参考应用
- **微信朋友圈**：整体布局和交互方式
- **小红书**：图片展示和话题标签
- **Instagram**：图片网格布局

### 设计原则
1. **简洁明了**：界面简洁，功能清晰
2. **易于操作**：操作流程顺畅，减少用户学习成本
3. **视觉舒适**：使用马卡龙配色，视觉柔和舒适
4. **突出重点**：使用玫红色突出重要操作按钮
