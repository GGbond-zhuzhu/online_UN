## 🚀 使用方法

### 访问页面

访问: http://localhost:5174/register

或从登录页面点击"还没有账号？注册新账号"链接

### 注册流程

1. **填写注册信息**
   - 输入用户名（4-20位，字母数字下划线）
   - 输入手机号（11位）
   - 输入邮箱（选填）
   - 输入密码（6-20位，包含大小写字母、数字和特殊字符）
   - 确认密码
   - 输入验证码（先发送验证码）

2. **同意服务条款**
   - 勾选"我已阅读并同意《服务条款》和《隐私政策》"

3. **提交注册**
   - 点击"注册账号"按钮
   - 等待注册成功

4. **注册成功**
   - 显示成功提示
   - 5秒后自动跳转到首页
   - 或点击"立即跳转"按钮
