# E卡通页面测试指南

## 📋 测试前准备

### 1. 启动后端服务
确保后端服务运行在 `http://localhost:8080`

### 2. 启动前端开发服务器
```bash
cd vue3-cross-platform
npm run dev:web
```

服务器将在 `http://localhost:5173` 启动

### 3. 访问页面
在浏览器中打开：`http://localhost:5173/ecard`

## 🐛 常见问题排查

### 问题1：页面空白
- 检查浏览器控制台是否有错误
- 检查路由配置是否正确
- 检查组件导入路径是否正确

### 问题2：API请求失败
- 检查后端服务是否启动
- 检查代理配置是否正确
- 检查API路径是否正确

### 问题3：样式显示异常
- 检查CSS变量是否定义
- 检查响应式断点是否正确
- 检查浏览器兼容性

### 问题4：定位功能不工作
- 检查浏览器是否允许定位权限
- 检查HTTPS环境（某些浏览器要求）
- 检查定位API是否可用

## 🎯 重点测试项

1. **用户认证流程** - 确保不同身份用户都能正常认证
2. **临时卡申请** - 确保游客可以申请临时卡
3. **余额显示和充值** - 确保金额计算准确
4. **二维码刷新** - 确保倒计时和刷新功能正常
5. **响应式布局** - 确保在不同设备上正常显示
