# 测试指南

## 🚀 快速启动测试

### 1. 启动开发服务器

在 PowerShell 中执行：

```powershell
cd vue3-cross-platform/packages/web
npm run dev
```

或者使用分号分隔（PowerShell语法）：

```powershell
cd vue3-cross-platform/packages/web; npm run dev
```

### 2. 启动后端服务（可选，用于测试API）

如果后端未运行，需要先启动：

```powershell
cd vue3-cross-platform/packages/backend
mvn spring-boot:run
```

## 🐛 常见问题排查

### 问题1：开发服务器无法启动

**可能原因：**
- 端口5173被占用
- node_modules未安装
- 依赖版本冲突

**解决方法：**
```powershell
# 检查端口占用
netstat -ano | findstr :5173

# 重新安装依赖
cd vue3-cross-platform/packages/web
rm -rf node_modules
npm install

# 或使用pnpm
pnpm install
```

### 问题2：页面显示空白

**可能原因：**
- 路由配置错误
- 组件导入路径错误
- TypeScript编译错误

**解决方法：**
1. 检查浏览器控制台错误信息
2. 检查终端编译错误
3. 确认所有组件文件存在

### 问题3：API请求失败

**可能原因：**
- 后端服务未启动
- API地址配置错误
- 跨域问题

**解决方法：**
1. 确认后端服务运行在 http://localhost:8080
2. 检查 vite.config.ts 中的代理配置
3. 检查浏览器控制台的网络请求

### 问题4：Font Awesome图标不显示

**可能原因：**
- CDN链接未加载
- 网络问题
- 图标类名错误

**解决方法：**
1. 检查 index.html 中的CDN链接
2. 检查浏览器网络请求，确认CSS文件已加载
3. 检查图标类名是否正确（fas fa-xxx）
