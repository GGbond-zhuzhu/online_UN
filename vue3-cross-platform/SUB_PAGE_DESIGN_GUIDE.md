# 子页面设计规范文档

## 设计原则

### 1. 背景色规范
- **页面背景**：必须使用渐变色背景
- **推荐渐变方案**：
  - 淡紫蓝渐变：`linear-gradient(135deg, #f9f0ff 0%, #e6f7ff 100%)`
  - 淡粉蓝渐变：`linear-gradient(135deg, #ffeef7 0%, #e6f7ff 100%)`
  - 淡绿蓝渐变：`linear-gradient(135deg, #f0fff4 0%, #e6f7ff 100%)`
  - 淡橙蓝渐变：`linear-gradient(135deg, #fff5e6 0%, #e6f7ff 100%)`

### 2. 单原色马卡龙色系规范

所有非背景元素必须使用单原色（非渐变），采用淡淡的马卡龙色系：

#### 主要色系
- **淡蓝色**：`#C7CEEA` - 用于卡片、图标背景
- **淡粉色**：`#FFB5D8` - 用于主要按钮、高亮元素
- **淡绿色**：`#A8E6CF` - 用于成功状态、确认按钮
- **淡紫色**：`#D4A5F5` - 用于特殊功能、高级选项
- **淡橙色**：`#FFD3B6` - 用于警告、提醒
- **淡黄色**：`#FFE5B4` - 用于提示、信息
- **淡青色**：`#B8E6E6` - 用于辅助功能
- **淡玫瑰**：`#E8B4CB` - 用于次要按钮

#### 文字颜色
- **主文字**：`#333` - 标题、重要内容
- **次文字**：`#666` - 描述、次要信息
- **辅助文字**：`#999` - 提示、占位符
- **白色文字**：用于彩色背景上的文字

### 3. 卡片设计规范

#### 卡片背景
- **主卡片**：`#FFFFFF` 或 `rgba(255, 255, 255, 0.95)`
- **次要卡片**：`rgba(255, 255, 255, 0.8)`
- **卡片阴影**：`0 8rpx 30rpx rgba(255, 181, 216, 0.12)`（使用马卡龙粉的透明度）
- **卡片圆角**：`24rpx` 或 `20rpx`

#### 卡片装饰
- **顶部装饰线**：使用单原色马卡龙色，高度 `4rpx` 或 `6rpx`
- **边框**：`1rpx solid rgba(255, 181, 216, 0.15)`（极淡的马卡龙粉）

### 4. 按钮设计规范

#### 主要按钮
- **背景色**：单原色马卡龙色（如 `#FFB5D8`）
- **文字颜色**：`#FFFFFF`
- **圆角**：`20rpx` 或 `24rpx`
- **阴影**：`0 4rpx 15rpx rgba(255, 181, 216, 0.3)`

#### 次要按钮
- **背景色**：`#FFFFFF`
- **文字颜色**：单原色马卡龙色（如 `#FFB5D8`）
- **边框**：`2rpx solid` + 单原色马卡龙色

#### 图标按钮
- **背景色**：单原色马卡龙色
- **图标颜色**：`#FFFFFF`
- **圆角**：`50%`（圆形）或 `18rpx`（圆角矩形）

### 5. 图标设计规范

#### 图标背景
- 使用单原色马卡龙色作为图标背景
- 图标大小：`60rpx` - `80rpx`
- 图标圆角：`18rpx` - `22rpx`
- 图标阴影：`0 6rpx 20rpx rgba(0, 0, 0, 0.12)`

#### 图标装饰
- 可以使用径向渐变装饰（`radial-gradient`）增加立体感
- 但图标背景本身必须是单原色

### 6. 列表项设计规范

#### 列表项背景
- **默认**：`#FFFFFF` 或 `rgba(255, 255, 255, 0.95)`
- **激活状态**：`rgba(255, 181, 216, 0.1)`（极淡的马卡龙粉）
- **左侧装饰线**：使用单原色马卡龙色，宽度 `4rpx`

#### 列表项交互
- **点击反馈**：`transform: scale(0.98)`
- **悬停效果**：轻微阴影变化

### 7. 输入框设计规范

#### 输入框样式
- **背景色**：`#FFFFFF`
- **边框**：`2rpx solid rgba(255, 181, 216, 0.2)`
- **聚焦边框**：`2rpx solid` + 单原色马卡龙色（如 `#FFB5D8`）
- **圆角**：`20rpx` 或 `24rpx`
- **占位符颜色**：`#999`

### 8. 标签/徽章设计规范

#### 标签样式
- **背景色**：单原色马卡龙色
- **文字颜色**：`#FFFFFF`
- **圆角**：`12rpx` 或 `15rpx`
- **字体大小**：`20rpx` - `24rpx`
- **内边距**：`4rpx 12rpx`

### 9. 页面标题栏规范

#### 标题栏样式
- **背景色**：`#FFFFFF` 或 `rgba(255, 255, 255, 0.95)`
- **阴影**：`0 2rpx 10rpx rgba(0, 0, 0, 0.05)`
- **返回按钮**：使用单原色马卡龙色图标
- **标题文字**：`#333`，`32rpx`，`font-weight: 600`

### 10. 空状态设计规范

#### 空状态样式
- **图标颜色**：`#DDD` 或极淡的马卡龙色
- **文字颜色**：`#999`
- **图标大小**：`80rpx` - `120rpx`

## 禁止使用的样式

1. ❌ **禁止在非背景元素上使用渐变色**
   - 错误：`background: linear-gradient(...)` 用于按钮、卡片等
   - 正确：使用单原色 `background: #FFB5D8`

2. ❌ **禁止使用过于鲜艳的颜色**
   - 错误：`#FF0000`、`#0000FF` 等纯色
   - 正确：使用马卡龙色系 `#FFB5D8`、`#C7CEEA`

3. ❌ **禁止使用纯黑色或深灰色作为主要颜色**
   - 错误：`#000000`、`#333333` 作为按钮背景
   - 正确：使用马卡龙色系，文字可以使用 `#333`

## 参考设计

参考市面主流应用的设计风格：
- **微信小程序**：简洁的卡片设计，柔和的颜色
- **支付宝小程序**：渐变背景 + 单色卡片
- **小红书**：马卡龙色系，柔和的视觉体验
- **Keep**：运动风格的渐变背景 + 单色元素

## 实施检查清单

在完成子页面设计后，请检查：

- [ ] 页面背景使用了渐变色
- [ ] 所有卡片、按钮、图标使用单原色（非渐变）
- [ ] 使用的颜色都在马卡龙色系范围内
- [ ] 卡片有适当的阴影和圆角
- [ ] 交互反馈（点击、悬停）符合规范
- [ ] 文字颜色对比度足够，易于阅读
- [ ] 整体视觉风格统一、柔和、现代
