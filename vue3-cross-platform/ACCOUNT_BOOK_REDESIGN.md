## 🚀 使用方法

### 访问页面

从首页点击"账单"快捷入口，或直接访问：
```
/pages/ecard/account-book/index
```

### 主要功能

1. **查看统计**
   - 顶部卡片显示本月总消费、交易笔数、日均消费
   - 预算剩余金额

2. **添加记录**
   - 点击"记一笔"按钮或浮动添加按钮
   - 跳转到添加记录页面

3. **导入数据**
   - 点击"导入E卡通"按钮
   - 自动导入E卡通消费记录

4. **数据分析**
   - 点击"数据分析"按钮
   - 查看详细的周报分析

5. **设置预算**
   - 点击"预算设置"按钮
   - 输入本月预算金额
   - 查看预算使用进度

6. **查看分类**
   - 点击分类统计卡片中的分类项
   - 筛选显示该分类的记录

7. **查看趋势**
   - 切换"本周"或"本月"标签
   - 查看消费趋势柱状图
