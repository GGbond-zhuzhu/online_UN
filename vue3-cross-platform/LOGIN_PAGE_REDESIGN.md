- **桌面**: > 1024px - 左右分栏布局

- 桌面端：左右分栏，左侧品牌介绍，右侧登录表单

## 🚀 使用方法

### 访问页面

访问: http://localhost:5174/login

### 功能说明

1. **账号登录**
   - 输入用户名/手机号/邮箱
   - 输入密码
   - 可选择30天内免登录
   - 点击登录按钮

2. **手机号登录**
   - 输入手机号
   - 点击发送验证码
   - 输入验证码
   - 点击登录按钮

3. **扫码登录**
   - 切换到扫码登录标签
   - 使用APP扫描二维码
   - 可刷新二维码

4. **登录成功**
   - 显示成功提示
   - 5秒后自动跳转
   - 或点击立即跳转
