# 搜索界面重设计说明

## 设计目标
- 主色调：玫红色（#FF1493）突出重点
- 辅助色：马卡龙色系（淡粉、淡黄、淡蓝、淡紫、淡绿、淡橙等）
- 参考主流应用设计（如小红书、淘宝等）
- 功能不减少，可以增加
- 分区清晰，提升用户体验

## 主要改进

### 1. 色彩方案优化
- **主色调**：使用玫红色（#FF1493）作为主色调，应用于：
  - 搜索按钮（渐变背景）
  - 标题文字
  - 搜索图标
  - 重要提示文字
  - 选中状态的强调
  
- **马卡龙色系**：使用柔和的马卡龙色系作为辅助色：
  - 淡粉色（#FFE0F0）：二手商品、热门标签
  - 鹅黄色（#FFF9E6）：兼职岗位、筛选按钮
  - 淡蓝色（#E3F2FD）：行程安排
  - 淡紫色（#E1BEE7）：全部类型
  - 淡绿色（#C8E6C9）：行程管理
  - 淡橙色（#FFF0E6）：其他辅助元素

### 2. 搜索栏优化
- **输入框聚焦效果**：聚焦时显示玫红色边框和阴影，突出显示
- **搜索按钮**：使用玫红色渐变背景，更醒目
- **实时搜索建议**：输入时显示搜索建议下拉列表
- **视觉层次**：增强阴影和边框，提升视觉层次

### 3. 分区布局优化
- **卡片式设计**：所有区域使用卡片式设计，分区更清晰
  - 热门搜索卡片
  - 搜索历史卡片
  - 推荐分类卡片
  - 筛选区域卡片
  - 搜索结果卡片

- **间距优化**：增加卡片间距，提升可读性
- **圆角设计**：统一使用24rpx圆角，更现代

### 4. 新增功能

#### 4.1 实时搜索建议
- 输入关键字时自动显示搜索建议
- 点击建议项快速搜索
- 使用下拉列表样式，参考主流应用

#### 4.2 高级筛选功能
- **价格筛选**：0-50元、50-100元、100-300元、300元以上
- **时间筛选**：今天、最近3天、最近一周、最近一月
- **筛选徽章**：显示激活的筛选条件数量
- **重置和确认按钮**：方便用户操作

#### 4.3 推荐分类
- 新增推荐分类区域
- 6个常用分类：教材书籍、电子产品、生活用品、服装配饰、运动健身、美妆护肤
- 使用网格布局，图标+文字展示
- 点击分类快速搜索

### 5. 交互优化
- **点击反馈**：所有可点击元素都有点击缩放效果
- **过渡动画**：统一使用0.3s过渡动画，流畅自然
- **阴影效果**：使用玫红色阴影，与主色调呼应
- **聚焦状态**：输入框聚焦时显示明显视觉反馈

### 6. 搜索结果优化
- **卡片设计**：使用更现代的卡片设计
- **图标渐变**：不同类型使用渐变背景，更美观
- **标题加粗**：标题使用700字重，更突出
- **间距优化**：增加卡片间距和内边距

### 7. 空状态优化
- **图标背景**：使用淡粉色渐变背景
- **标题颜色**：使用玫红色，与主色调一致
- **建议标签**：使用淡粉色背景和玫红色文字

## 技术实现

### 新增状态管理
```typescript
// 搜索建议相关

const suggestions = ref<string[]>([])

// 筛选相关
const showFilterMenu = ref(false)

const selectedTimeFilter = ref<string>('')

// 推荐分类
const recommendedCategories = ref([...])
const priceFilters = ref([...])
const timeFilters = ref([...])
```

### 新增方法
- `handleInputFocus()`: 处理输入框聚焦
- `handleInputBlur()`: 处理输入框失焦
- `handleSuggestionClick()`: 处理搜索建议点击
- `handleCategoryClick()`: 处理分类点击
- `handlePriceFilter()`: 处理价格筛选
- `handleTimeFilter()`: 处理时间筛选
- `handleResetFilters()`: 重置筛选
- `handleConfirmFilters()`: 确认筛选

### 样式优化
- 统一使用玫红色作为主色调
- 使用马卡龙色系作为辅助色
- 增加卡片式设计
- 优化阴影和边框效果
- 统一圆角和间距

## 设计亮点

1. **主色调突出**：玫红色贯穿整个界面，突出重点元素
2. **分区清晰**：使用卡片式设计，每个区域都有明确的边界
3. **功能丰富**：新增搜索建议、筛选、推荐分类等功能
4. **交互流畅**：统一的过渡动画和点击反馈
5. **视觉统一**：统一的色彩方案和设计语言
