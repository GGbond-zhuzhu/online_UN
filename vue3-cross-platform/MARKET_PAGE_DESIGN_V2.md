# 校园集市页面重新设计文档

## 设计目标
- 主色调：柔和的玫红色（#FF6B9D / #E91E63），突出重点但不刺眼
- 辅助色：马卡龙色系（柔和的粉色、蓝色、绿色、黄色、紫色等）
- 参考设计：闲鱼、转转等主流二手交易平台
- 字体清晰：确保所有文字对比度足够，易于阅读

## 配色方案

### 主色调（玫红色系）
- **主色（重点突出）**：`#FF6B9D` - 柔和的玫红色，用于重要按钮、标签、强调元素
- **主色深色**：`#E91E63` - 用于文字、图标等需要更高对比度的地方
- **主色浅色**：`#FFB3D1` - 用于背景、边框等辅助元素
- **主色渐变**：`linear-gradient(135deg, #FF6B9D 0%, #FF8FB3 100%)` - 用于顶部栏、卡片等

### 马卡龙辅助色
- **粉色系**：`#FFB6C1` (樱花粉) - 用于标签、图标背景
- **蓝色系**：`#B0E0E6` (淡湖蓝) - 用于次要按钮、信息提示
- **绿色系**：`#98FB98` (薄荷绿) - 用于成功状态、在售标签
- **黄色系**：`#FFF8DC` (奶油黄) - 用于警告、热门标签
- **紫色系**：`#DDA0DD` (丁香紫) - 用于特殊标签、新上架
- **橙色系**：`#FFD4A3` (柔和橙) - 用于发布按钮、操作按钮

### 中性色
- **文字主色**：`#333333` - 主要文字内容
- **文字次色**：`#666666` - 次要文字、描述
- **文字辅助**：`#999999` - 辅助信息
- **背景色**：`#FFFFFF` - 卡片、内容区背景
- **背景浅色**：`#F8F9FA` - 页面背景、输入框背景
- **边框色**：`#E5E5E5` - 边框、分割线

## 字体规范

### 字体大小
- **大标题**：36rpx / 24px - 页面主标题
- **中标题**：32rpx / 20px - 区域标题
- **小标题**：28rpx / 18px - 卡片标题
- **正文**：26rpx / 16px - 正文内容
- **辅助文字**：24rpx / 14px - 描述、标签
- **小字**：22rpx / 12px - 次要信息

### 字体粗细
- **加粗**：600 / bold - 标题、价格、重要信息
- **中等**：500 / medium - 按钮文字、标签
- **常规**：400 / normal - 正文内容

### 行高
- **标题行高**：1.4 - 标题类文字
- **正文行高**：1.6 - 正文内容
- **紧凑行高**：1.2 - 标签、按钮

## 设计参考

### 参考平台
1. **闲鱼**：卡片式布局、清晰的分类标签、柔和的配色
2. **转转**：简洁的搜索栏、突出的发布按钮、清晰的商品信息展示
3. **小红书**：马卡龙配色、圆润的卡片设计、精美的图片展示

### 设计原则
1. **视觉层次**：使用颜色、大小、间距建立清晰的视觉层次
2. **呼吸感**：适当的留白，避免信息过载
3. **一致性**：统一的圆角、阴影、间距规范
4. **可读性**：确保文字与背景有足够的对比度（至少4.5:1）

## 页面结构

### App端页面结构
1. **顶部栏**（玫红色渐变背景）
   - 搜索框（白色背景，玫红色边框）
   - 快速操作按钮（发布、消息）
   - 特色标签横向滚动

2. **筛选栏**（白色卡片，玫红色强调）
   - 分类筛选（马卡龙色标签）
   - 排序选项（玫红色激活状态）
   - 价格快捷筛选（马卡龙色按钮）

3. **商品展示区**
   - 瀑布流布局（2列）
   - 商品卡片（白色背景，圆角，阴影）
   - 热门/新上架标签（马卡龙色）
   - 收藏按钮（玫红色）

4. **推荐区**
   - 轮播图（精选商品）
   - 猜你喜欢（网格布局）

### Web端页面结构
1. **顶部搜索栏**（白色背景，玫红色强调）
   - 搜索框（玫红色边框）
   - 操作按钮组

2. **筛选区域**（白色卡片）
   - 分类、成色、价格筛选
   - 排序和价格快捷筛选

3. **主内容区**（左右布局）
   - 左侧：商品列表（网格布局）
   - 右侧：侧边栏（特色标签、热门分类、快捷操作、交易提示）

4. **页脚**（深色背景）

## 交互设计

### 按钮状态
- **默认状态**：马卡龙色背景，白色文字
- **悬停状态**：颜色加深10%，轻微上浮
- **激活状态**：玫红色渐变，白色文字
- **禁用状态**：灰色背景，50%透明度

### 卡片交互
- **默认状态**：白色背景，轻微阴影
- **悬停状态**：阴影加深，轻微上浮
- **点击状态**：轻微缩放（0.98）

### 动画效果
- **页面加载**：淡入动画（fadeIn）
- **卡片出现**：上浮动画（fadeInUp）
- **标签切换**：颜色过渡（0.3s ease）
- **按钮点击**：缩放反馈（0.95 scale）

## 响应式设计

### App端
- 固定2列瀑布流布局
- 适配不同屏幕尺寸（375px - 768px）

### Web端
- 桌面端：左右布局，商品网格4-5列
- 平板端：左右布局，商品网格3列
- 移动端：单列布局，侧边栏收起

2. **性能优化**：图片懒加载、列表虚拟滚动

4. **浏览器兼容**：确保主流浏览器正常显示
